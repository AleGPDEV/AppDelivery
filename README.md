# AppDelivery

Herramientas para la gestión de deliverys.

- **[optimizador-rutas/](optimizador-rutas/)** — app web (sin instalación) para pegar los pedidos del día y obtener el recorrido más eficiente por calles reales, con un link de Google Maps listo para navegar.
- **[tracking-en-vivo/](tracking-en-vivo/)** — servidor con una página para que cada delivery comparta su ubicación en vivo y un panel para verlos a todos en un mapa.

Ver **[DOCUMENTACION.md](DOCUMENTACION.md)** para el detalle técnico de cómo funciona todo por dentro.
